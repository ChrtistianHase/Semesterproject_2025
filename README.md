This is my Semesterproject for the Bachelors Degree Physics odf the Earthsystem B.Sc.
at Kiel University.

The aim of The project is to determine the bathymetry under the Getz Ice Shelf in Antarctica.
As this area is inaccessible to research ships airborne gravimetric data is used,
to create a topographic map of the area.

create the environment in conda forge, in an IDE that can work with jupyter notebooks, 
by installing the dependencies listed in Semesterproject.yml
